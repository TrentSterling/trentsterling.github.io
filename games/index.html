Tront's Games

Production work, games, experiments, and tools by Trent Sterling (Tront), Network Programmer and Unity Generalist on Project Demigod. Building in Unity, C#, VR, multiplayer, and GPU systems since 2009. Most of the browser games here are one self-contained HTML file: nothing to install, nothing to download.

Project Demigod (2025-Present)

Contract Network Programmer + Unity Generalist for Omnifarious Studios on the physics-driven VR superhero sandbox; netcode, gameplay, menus, IK, ragdoll, shaders, and performance.
