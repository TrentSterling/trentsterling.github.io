About Trent Sterling

I'm Trent Sterling, known online as Tront. Since 2025 I've been the contract Network Programmer and Unity Generalist on Project Demigod for Omnifarious Studios. My production work spans multiplayer architecture, gameplay, menus, IK, ragdoll systems, shaders, and performance across Quest and PC VR.

I've made games since 2009, starting with Halo CE, Minecraft, and Garry's Mod. Outside Project Demigod, I build multiplayer frameworks, GPU experiments, browser games, and native developer tools.

My Core Focus Areas

  • Production Unity & VR: Shipping features across gameplay, UI, IK, physics, rendering, tools, and optimization on Quest and PC VR.
  • Multiplayer & Networking: Production netcode plus standalone Unity systems built directly on Epic Online Services P2P.
  • Rendering & GPU Systems: HLSL, compute shaders, WebGPU, voxel rendering, procedural generation, and performance work.
  • Developer Tools: Native Windows tools in Rust, Unity editor tooling, browser utilities, backend services, and automation.

Technical Background

I work across the stack when a project needs it, but my strongest lanes are multiplayer architecture, systems-heavy Unity work, VR interaction, and GPU-driven rendering.

Additional Skills

  • Languages: C#, Rust, Go, TypeScript, JavaScript, Python, HLSL, WGSL.
  • Platforms: Windows, Web, Meta Quest, PC VR, Android, and cross-platform Unity.
  • Tools & Pipelines: Unity editor extensions, build automation, profiling, Blender, and content tooling.
